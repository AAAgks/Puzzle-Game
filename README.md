# 拼图游戏 (Puzzle Game)

Java Swing 实现的 4×4 经典滑块拼图游戏。

## 游戏截图

> 运行 `App.java` 启动游戏。

## 玩法

- 打乱 4×4 的图片切片，留出一个空白格
- 通过**键盘方向键**移动切片，将图片还原为原始顺序即为胜利

## 操作说明

| 按键 | 功能 |
|:---:|------|
| ← → ↑ ↓ | 相邻切片滑入空白格（按键方向上的拼图块填入空白） |
| 空格 | 长按预览完整图片（松开恢复拼图） |
| 回车 | 一键完成（直接显示复原结果） |
| 菜单栏 | 切换图片集 / 重新游戏 |

## 移动逻辑

空白格用 `0` 表示，保存在 `(x, y)` 坐标。方向键按下时：

1. 检查空白格是否在对应边界（如在最右侧则 `←` 无效，以此类推）
2. 将相邻格的值写入空白格 `data[x][y] = data[x + dx][y + dy]`
3. 将相邻格置为 0 `data[x + dx][y + dy] = 0`
4. 更新空白坐标 `(x, y)`
5. 步数 +1，重新渲染界面

```
← 左：data[x][y] = data[x][y+1]  → 右边块左移填入空白
↑ 上：data[x][y] = data[x+1][y]  → 下面块上移填入空白
→ 右：data[x][y] = data[x][y-1]  → 左边块右移填入空白
↓ 下：data[x][y] = data[x-1][y]  → 上面块下移填入空白
```

> 设计为**方向键 = 相邻块滑入空白格的方向**（即 ← 让右边的块左移填入空白）。

## 环境要求

- JDK 8+
- IntelliJ IDEA（推荐）或任意 Java IDE

## 运行

用 IDE 打开项目，运行 `src/App.java` 的 `main` 方法即可。
